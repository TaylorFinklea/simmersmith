Support

Get help with SimmerSmith

If something is broken, confusing, or missing, send a note with enough detail to reproduce the issue.

Contact

Email: support@finklea.dev

Secondary support channel: GitHub Issues

Do not send API keys, iCloud exports, backup files, or private household data. If a sample is needed, remove personal and sensitive information first.

What to include in a bug report

  • What you were trying to do and what happened instead
  • The app version or build number
  • Your device model and iOS version
  • Whether the problem affects an owner or participant in a shared household
  • Whether you were online or offline
  • Screenshots or a recording, after removing private information

Common support topics

  • iCloud household setup, sharing, or synchronization
  • Recipe import from a URL, photo, camera scan, or PDF
  • AI provider setup with your own API key
  • Grocery and Apple Reminders synchronization
  • On-device household backups and recovery

For privacy questions, email support@finklea.dev and include “Privacy” in the subject line.
